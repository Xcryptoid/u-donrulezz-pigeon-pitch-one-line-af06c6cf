investors for its startup.

## The pitch

> PigeonPost delivers across the city in minutes, powered by breadcrumbs
> and spite. Invest now, before the seagulls IPO.

## How it works

`entry.txt` holds the pitch, written in advance. `main.py` is a
standard-library-only copier: it copies `entry.txt` into
`MAKEFUN_OUTPUT_DIR/entry.txt`, so the grader receives exactly the text
that was written and checked here, byte for byte, every run.

## Files

- `entry.txt` — the one-line pitch (118 characters)
- `main.py` — stdlib-only copier (`os` + `shutil`)
